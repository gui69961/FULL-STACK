## 📖 Sobre

Espaço dedicado aos meus projetos e estudos de **desenvolvimento full stack**, passando pelo **front-end** (o que o usuário vê)
e pelo **back-end** (regras de negócio e dados), com **JavaScript** como linguagem principal.

## 🎯 O que você encontra aqui

- Interfaces web com HTML, CSS e JavaScript
- Lógica e regras de negócio no back-end
- Integração entre front-end e back-end
- Prática de boas práticas e organização de projeto

## ▶️ Como executar

1. Instale o **Node.js** (versão LTS) em https://nodejs.org
2. Clone o repositório:

```bash
git clone https://github.com/gui69961/FULL-STACK.git
cd FULL-STACK
```

3. Entre na pasta do projeto desejado, instale as dependências e inicie:

```bash
cd nome-do-projeto
npm install
npm start
```

> Cada projeto pode ter instruções próprias. Veja o README dentro da pasta dele, quando houver.
